# Demo Script – 2 to 3 Minutes

## Scene 1 – Introduction
Say:
"Hello, this is my Electricity Usage Analyzer developed using C. The project analyzes monthly electricity consumption and estimates the bill using predefined slab rates."

## Scene 2 – Show the Repository
Open the GitHub repository and show:
- README.md
- src/electricity_usage_analyzer.c
- docs/project_report.md
- docs/demo_script.md
- data/sample_usage.csv

## Scene 3 – Compile
Run:
gcc src/electricity_usage_analyzer.c -o electricity_analyzer

## Scene 4 – Execute
Run:
./electricity_analyzer

Enter sample monthly data.

## Scene 5 – Explain Output
Show:
- monthly units
- estimated bill
- total consumption
- average consumption
- highest and lowest usage
- usage status

## Scene 6 – Conclusion
Say:
"The prototype completes the workflow from data input to consumption analysis and estimated billing. The repository contains the source code, documentation and test data for reproducible demonstration."
